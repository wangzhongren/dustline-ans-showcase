# 模块说明：项目管理

## 这个模块做什么

项目管理负责让多个角色按同一套契约协作交付 DUSTLINE：确认架构与依赖顺序、评审跨角色契约、向独立角色上下文分派任务、核对实际证据，并维护项目级文档。它自己只实现一个应用代码组件——跨角色共享事件总线。

## 边界

- 只写 `src/common/shared/event-bus.js`、`test/项目管理/`、`docs/architecture.md`、`docs/architecture/shared-components.md`、`docs/project-rules.md`、`docs/scheduling/` 和本角色文档。
- 不写其他角色的代码、角色卡/边界、`.ans/project.json` 或治理文档。
