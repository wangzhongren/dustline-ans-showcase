# DUSTLINE v3 升级协调记录

## 用户能看到什么

1. 敌人从无人机/机械单位改为**人类士兵**：步枪兵、重机枪手、突击兵，带头盔、面罩、防弹衣、弹匣袋、护膝、手套和步枪，会持枪、奔跑、射击、受击和死亡；爆头造成双倍伤害，击杀信息会标记“爆头”。
2. 第一人称武器重做为高细节 AR-15，带戴手套的双手、红点镜、抛壳、枪口闪光/烟雾、换弹动画、后坐/镜头滚转/FOV 冲击；枪声分层。
3. 场景增加 HESCO、沙袋墙、集装箱门锁杆、托盘、轮胎、帐篷、警戒塔、围栏、警示牌、弹药箱、探照灯、碎石/草丛/污渍；低角度阳光/长阴影/雾/尘土；高画质 SSAO/Bloom/色彩分级/AA/暗角/颗粒，低画质可关闭后处理。
4. 菜单与暂停新增设置面板：鼠标灵敏度、ADS 灵敏度倍率、FOV、主音量、画质（高/低）；本地保存，重启后仍生效。
5. HUD 增加爆头命中标记、方向受击指示、人类敌人名称；不再出现无人机/幽影或霓虹。

## 关键协调与修复

1. 美术先下载并验证 4 个 Quaternius CC0 人类 GLB，记录实际动画名、身高、朝向、根运动与缺失剪辑；敌方服务据此做动画映射与回退。
2. 游戏管线先更新 Model：人类敌人配置、设置默认/范围、事件载荷、`applySettings/getSettings/getPerformance`，并修复战斗与 Pipeline 重复发 `hud:damage` 的问题（Pipeline 单一所有者）。
3. 真实中心射线发现屏幕被巨大暗板遮挡：根因是敌方装备继承了 GLB `CharacterArmature` 的 100× 缩放；敌方服务按骨骼世界缩放补偿装备/步枪，face-mask 恢复 0.17×0.11×0.11 m，环境与战斗分别排除了道具与视图模型。
4. 真实截图发现武器护木/弹匣偏蓝、枪托偏红：根因是 `Fabric084` 颜色贴图本身偏蓝、`Wood066` 偏红被直接用于手套/袖口/木件；战斗改为深色聚合物/枪金属，布料/木材只用颜色值 + 法线/粗糙度。
5. 美术复核最终菜单、对局、HIP/ADS 截图后给出静态视觉验收 YES；保留三项非阻断打磨（敌方军服绿色/红帽、HESCO 近处织纹、太阳 Bloom）。
6. 客户反馈“右键 ADS 镜内全黑”：红点镜体原为实心盒，前脸挡住镜片；战斗改为四面薄壁开放隧道、低不透明度且 depthWrite 关闭的镜片、高亮红点；独立测试在真实 Electron pointer lock ADS 下采样中心亮度 130.17/255、镜片中心 40×40 113.57/255、红点 37 像素，E2E 5/5；重新打包后再次采样 142.79/255 与 113.63/255、红点 36 像素。修复前后截图保留在 `test/独立测试/fixtures/screenshots-v3-ads-fix/`。

## 验证结果

- 角色套件：209/209（事件总线 9、美术 11、环境 28、战斗 64、敌方 38、管线 32、界面 27）。
- 独立测试：集成 12/12、Electron E2E 4/4；覆盖人类敌人、爆头 52、血雾而非爆炸、方向受击、波次 2/3 组成、设置转发/持久化、低画质关闭后处理、死亡/重开。
- 构建：`npm run build` 通过（68 modules，JS 1,008.43 kB，gzip 294.05 kB，仅有 >500 kB chunk 警告）。
- 打包：`npm run pack`、`npm run dist` 产出 `release/win-unpacked/DUSTLINE.exe`（18:33）与 `release/DUSTLINE Setup 1.0.0.exe`（18:34）；解包应用 JS 与 `dist` 哈希一致（`777f09e9…fb35e`），独立测试启动验证标题/开始/HUD/人类敌人。
- 启动：`npm start` 打开窗口标题 `DUSTLINE · 尘埃战线`。
- 性能：6 个步枪兵、1584×861、高/低画质各 3 秒采样约 180 fps（受 rAF/显示节奏限制）；30 敌人、真人手感/听音、安装包安装卸载/签名仍未验证。
