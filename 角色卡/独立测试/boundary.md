# 边界文档：独立测试

## 第 1 节：可修改的文件与目录

| 类型 | 可操作路径 | 用途 |
| --- | --- | --- |
| 目录 | `test/独立测试/integration/` | 跨角色接口与集成测试 |
| 目录 | `test/独立测试/e2e/` | Electron 端到端与完整流程测试 |
| 目录 | `test/独立测试/fixtures/` | 测试夹具与辅助代码（不被生产代码引用） |
| 单文件 | `角色卡/独立测试/docs/test-plan.md` | 测试方案与覆盖范围 |
| 条件目录 | `角色卡/独立测试/docs/reports/` | 日期化测试报告 |
| 单文件 | `角色卡/独立测试/feature-map.md` | 功能导航（无直接业务功能） |
| 单文件 | `角色卡/独立测试/memo.md` | 本角色工作线索 |
| 单文件 | `角色卡/独立测试/changelog.md` | 变更日志 |
| 单文件 | `角色卡/独立测试/functional-description.md` | 本角色说明 |
| 条件目录 | `角色卡/独立测试/docs/design/` | 测试设计记录 |
| 条件目录 | `角色卡/独立测试/docs/change/` | 变更记录 |
| 条件目录 | `角色卡/独立测试/docs/fix/` | 修复复测记录 |

不在本表或本表目录范围内的文件默认只读。新增目录、转移所有权或删除单独列出的文件需要 ANS Governance 更新本节并重新验收。
